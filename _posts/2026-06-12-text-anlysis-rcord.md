## 만든 것
1. 정적 사이트 생성기 Jekyll로 HTML 만들기

- config.yml로 Jekyll 사이트에 적용되는 설정 입력

- 프론트매터를 입력하고 md파일을 만들면 자동으로 Jekyll이 처리 

- Jekyll은 _이 붙은 폴더에 있는 파일들은 특별하게 처리

```bash
_config.yml --> 홈페이지에 적용되는 설정
_posts/     --> 시간 순으로 쌓이는 글
_drafts/    --> 아직 홈페이지에 업로드 되지 않는 초안
_includes/  --> 여러 페이지에 넣을 HTML 조각들을 저장
_layouts/   --> 테마를 제공
```

2. JavaScript로 페이지를 동적으로 구현(버튼)

-마크다운 파일 안에 HTML 태그를 작성하고, 식별할 수 있는 이름표 붙이기
```bash
<button id="my-btn">클릭!</button>
```

- 로직이 담긴 js 파일 만들기
```bash
querySlector --> id나 class로 요소를 찾음.
addEventListener --> 이벤트와 함수를 연결
```

-md 파일에 스크립트 소스 부여
```bash
<script src="파일경로.js"></script>
```

3. 분석결과와 차트 만들기

-fetch로 데이터 가져오기
분석할 원본 파일과 불용어 목록을 담은 데이터를 fetch로 가져옴

-데이터 가공하기
텍스트를 단어 단위로 쪼개고 공백이나 문장부호 등의 문장부호를 제거하는 등 데이터를 가공해 분석하기 쉽게 함

-<canvas>를 만들고 가져오기
HTML에 <canvas>를 만들고 id나 클래스를 통해 가져오기

-new Chart로 차트 완성

위의 도구들을 이용해 텍스트를 입력하면 가장 빈도가 높은 20개의 단어를 막대그래프로 보여주는 사이트를 제작함.

## 겪은 문제
gothic.md 페이지에서 
차트가 그려지지 않고 콘솔창에 에러가 뜸
문제는 analyzer.md에서 스크립트 소스를 가져오는 과정에서 anylzer.js를 잡음.
gothic.md에는 버튼이 없기에 에러가 뜨고 텍스트를 받아오지 못해 그래프도 그려지지 않음.
```bash
<script src="/assets/js/analyzer.js"></script>를
<script src="/assets/js/gothic.js"></script> 로 변경해서 해결
```

## 분석에서 발견한 것
텍스트 분석기로 모비딕을 돌려본 결과 chapter라는 단어가 상위권에 위치해있다. 원본 텍스트를 보니 모비딕은 짧은 챕터들이 135개로 구성되어있었다. 즉 자주 쓰이는 단어 빈도를 통해 주제 뿐 아니라 소설의 구성까지도 볼 수 있다는 점이 흥미로웠다. 비슷한 시기에 같은 문화권에서 쓰인 여러 텍스트들을 이렇게 비교해보면 이러한 수많은 챕터를 가진 구성이 당시의 유행인지 작가가 가진 특징인지, 단일한 작품에서 시도한 구성인지 등을 밝힐 수 있을 것으로 보임.
